Frontend Next.js de LasLongDeco. Ver `README.md` en la raíz del repo para la documentación completa (backend, modelo de datos, panel admin, variables de entorno).

## Correr en local

```bash
npm install
npm run dev     # necesita el backend .NET corriendo, ver .env.local en la raíz de este directorio
```

Abrir [http://localhost:3000](http://localhost:3000).
